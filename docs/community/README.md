## Community Values

### 1. Honesty First
DUM360's competitive moat is credibility. Every claim must be consistent with [docs/compute-benchmark.md](../compute-benchmark.md). We don't hype, we don't overclaim, and we say "we don't do that" where we honestly don't.

### 2. India-First, Not India-Only
The platform is built for India's sovereignty needs, but the code is open-source. Contributors from anywhere are welcome — just understand that 100% Indian-hosted platform, DPDP-aligned, and UPI payouts are non-negotiable design constraints.

### 3. Build in Public
Design discussions, ADRs, and decisions happen in the open. Use GitHub Issues and Discussions. No private Slack/Discord that excludes contributors.

### 4. Respect the Stage
We're at Phase 1 (Waitlist). The platform doesn't exist yet. That's the opportunity — early contributors shape the architecture from scratch. It also means patience and long-term thinking.

### 5. Utility Over Hype
DUM360 is national infrastructure, not a startup looking for a valuation. Write code and docs that will be read by government engineers, university IT admins, and students. Clarity > cleverness.
